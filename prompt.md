# Objetivo

Nosso primeiro objetivo é adaptar o frontend mobile para ficar idêntico ao protótipo do Figma.

Protótipo:
https://www.figma.com/design/pYCePi7jJ1ygAfp1iMYgcl/Desenvolvimento-Mobile-II?node-id=15-6058&t=sXvdrcgOQ2TIr9p6-4

# Instruções

- Analise cuidadosamente o layout, espaçamentos, tipografia, cores, tamanhos, alinhamentos, bordas, ícones e todos os elementos visuais presentes no protótipo.
- Implemente a primeira página do aplicativo seguindo o design do Figma.
- O resultado deve ser visualmente idêntico ao protótipo.
- Não faça aproximações, interpretações ou adaptações visuais sem necessidade.
- Utilize os componentes, estilos e recursos necessários para reproduzir fielmente o design.
- Certifique-se de que o comportamento responsivo seja compatível com dispositivos móveis.

# Validação Obrigatória

Após cada alteração:

1. Execute a aplicação.
2. Utilize o Playwright MCP para acessar a tela implementada.
3. Capture evidências visuais da página.
4. Compare o resultado com o protótipo do Figma.
5. Identifique qualquer diferença visual existente.
6. Corrija as divergências encontradas.
7. Repita o processo até que a tela esteja visualmente idêntica ao protótipo.

# Critérios de Aceitação

A tarefa só pode ser considerada concluída quando:

- A tela estiver EXATAMENTE IGUAL ao protótipo do Figma.
- Todos os elementos visuais estiverem posicionados corretamente.
- Espaçamentos, tamanhos e alinhamentos estiverem consistentes com o design original.
- Cores, fontes, pesos e estilos estiverem equivalentes ao protótipo.
- A validação final tiver sido realizada utilizando Playwright MCP.

# Regra Importante

NÃO me entregue a tarefa como concluída sem antes:

- Executar a aplicação.
- Validar utilizando Playwright MCP.
- Confirmar visualmente que a implementação está EXATAMENTE IGUAL ao protótipo.
- Corrigir qualquer diferença encontrada durante a validação.

Caso exista qualquer divergência visual, continue iterando até que o resultado seja indistinguível do design do Figma.
